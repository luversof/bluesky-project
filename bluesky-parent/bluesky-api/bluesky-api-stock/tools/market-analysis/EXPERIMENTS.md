## 관찰

- 종목별 FLAT 예측 비율은 실제 FLAT 비율과 대체로 맞는다(채권 · 달러 · 리츠는 FLAT, 개별주는 UP/DOWN). 금(KODEX 골드선물)만 D+1 FLAT 과다(예측 51% 대 실제 29%).
- confidence 60 이상이 가장 잘 맞았다(D+1 69% · D+5 56%) - 화면의 신뢰도 구간을 60+ 로 나눈 근거.
- (11-12, 삼성전자 v3 opus 245 일) D+1 예측은 간밤 SOX 방향과 88% 같다 - 적중 59.6 은 SOX 방향 규칙(55.1)보다 조금 높을 뿐. 같은 입력으로 더 짜낼 여지가 작아 새 정보가 필요하다.
- (11-12) 다음 날 변화율과 입력 지표 상관(D+1): SOX 0.37 · COMP 0.34 · VIX -0.33 · USD/KRW -0.32 · SPX 0.31 · KOSPI -0.16 · 전일 변화 -0.12. D+5 는 모두 0.16 이하.
- (11-12) SOX 와 원/달러가 엇갈릴 때가 약하다: SOX 상승 + 원화 약세(62 일) opus 적중 53.2 - 실제 UP 34 · DOWN 19 인데 60 일을 UP. SOX 하락 + 원화 강세(44 일) 54.5. 같은 쪽일 때는 60.0 · 70.4.
- (11-12) 롤링 60 일 회귀(SOX · USD/KRW · VIX · KOSPI) 방향 적중 54.1 - opus(같은 날 60.0)보다 낮다. 규칙 · 회귀로 LLM 을 대신하지 않는다.
- (11-12) 신뢰도별 D+1 적중: 30 대 8/12 · 40 대 61/114 · 50 대 59/96 · 60 대 16/21 · 70 대 2/2 - 60 이상만 확실히 높다.
